# Sinon Warring States Game

A web-based text strategy game set in Japan's Sengoku period.

## Vision
- Theme: Sengoku-era grand strategy
- Core loop: population/economy/military governance + diplomacy/warfare
- Goal: 天下布武

## Stack (aligned with sinon_blog deployment style)
- Next.js (App Router) + TypeScript
- TailwindCSS + shadcn/ui + Radix UI + Framer Motion
- Prisma
- Cloudflare Workers + D1 + R2 + KV

## Environments
- Production: game.sinon.live
- Development: dev-game.sinon.live

## AI Direction
- Multi-faction hostile AI inspired by Nobunaga's Ambition style
- Strategic / operational / tactical decision layers
